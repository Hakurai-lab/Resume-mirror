利用料と残高の確認方法
まず、安心してください。
このツールの1回のAI呼び出しで使う量は、ごくわずかです。職務経歴書と面接シートを一通り作っても、通常は数十円程度に収まります。

残高と使用量を見る場所

残高は、このツールからは取得できません（Anthropicが外部に公開していないため）。ご自身のConsoleで確認してください。

1
Anthropic Console を開く console.anthropic.com にログインします。
2
残高を見る 左メニューの「Billing（お支払い）」に、現在の残高（Credit balance）が表示されます。ここから追加もできます。
3
使用量を見る 左メニューの「Usage（使用状況）」で、日ごと・モデルごとの使用量と金額を確認できます。実際にいくら使ったかは、ここが正確です。

費用を抑えたいとき

  • STEP 0 でモデルを「軽量」に切り替えると、費用が下がります
  • 面接シートは項目ごとに作り直せます。全部作り直すより、気になる項目だけやり直すほうが安く済みます
  • 職務経歴書の入力・編集・PDF出力は、AIを使わなければ費用はかかりません

残高が切れたら

AIボタンを押したときに「残高が不足しているようです」と表示されます。その場合も、入力内容はこの端末に残っています。残高を追加すれば、続きから作業できます。急ぎでない場合は、STEP 0 の「AIを使わずに進む」で、職務経歴書の確認とPDF出力だけ行うこともできます。

プライバシーポリシー

1. 運営者は、あなたの情報を収集しません

本サービスはサーバーを持たず、利用者の入力内容を送信・収集・保存する仕組みを一切持ちません。氏名、連絡先、職務経歴、その他入力されたすべての情報は、運営者に届きません。

2. 入力内容の保存場所

入力内容は、利用者ご自身の端末のブラウザ内（ローカルストレージ）に保存されます。これにより、画面を閉じても作業を再開できます。他の人と共有する端末をお使いの場合は、作業後に画面下の「保存を消去」を押してください。

3. APIキーの取り扱い

入力されたAPIキーは、Anthropic社へのAI呼び出しにのみ使用され、それ以外のいかなる送信先にも送られません。APIキーは初期設定では保存されません。「この端末に保存する」を選択した場合に限り、端末のブラウザ内にのみ保存されます。共用端末では選択しないことを推奨します。

4. AIへの送信について

「AIで整える」「AIで作成」などの機能を使用した際、その処理に必要な入力内容（職務経歴やスキルの記述など）が、利用者ご自身のAPIキーを用いてAnthropic社に送信されます。送信された情報の取り扱いは、Anthropic社のプライバシーポリシーに従います。AIに送信したくない内容は、入力しないでください。

5. アクセス解析・Cookie

本サービスは、アクセス解析ツールや広告目的のCookieを使用していません。ただし、本サービスはGitHub Pages上で公開されているため、ホスティング事業者側でアクセスに関する記録（IPアドレス等）が保持される可能性があります。
